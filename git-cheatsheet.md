# Основные команды Git

---

### Первичная настройка и инициализация

| Команда | Описание |
| --- | --- |
| git version | Проверить версию установленного Git. |
| git config --global user.name "имя" | Установить имя пользователя для подписи всех коммитов |
| git config --global user.email "имеил" | Установить почту пользователя. |
| git init -b main | Инициализировать новый репозиторий в текущей папке с главной веткой main. Создаёт скрытую папку .git |
| pwd | Вывести текущий полный путь рабочей директории |
| ls | Вывести список файлов и папок в текущей директории. |
| cd <путь> | Перейти в указанную папку (cd .. — перейти на уровень выше т.е обратно) |

---

### Статус, индексация и коммиты

| Команда | Описание и назначение |
| --- | --- |
| git status | Показать состояние файлов в рабочей директории и индексе |
| git add <file> | Добавить конкретный файл в индекс |
| git add . | Добавить все изменённые и новые файлы текущей папки в индекс |
| git commit -m "комментарий" | Создание коммита и комментария к нему |
| git restore <file> | Отменить изменения в файле, вернув его к состоянию последнего коммита |

> Обозначения статусов в VS Code и Git:
> * U (Untracked) — новый неотслеживаемый файл
> * A (Added) — файл добавлен в индекс
> * M (Modified) — файл изменён по сравнению с последним коммитом

---

### Анализ истории изменений

| Команда | Описание и назначение |
| --- | --- |
| git log | Полный вывод истории коммитов. Для выхода из режима просмотра q |
| git log --oneline | Компактный вывод истории коммитов |
| git show <hash> | Детальный просмотр конкретного коммита: метаданные и diff |

---

### Управление ветками

| Команда | Описание и назначение |
| --- | --- |
| git branch | Просмотр списка всех локальных веток |
| git branch <имя_ветки> | Создание новой ветки без перехода на неё |
| git switch <имя_ветки> | Переключение на существующую ветку (типа git checkout <имя_ветки>) |
| git switch -c <имя_ветки> | Создание новой ветки и переход на неё |
| git switch - | Переход на предыдущую ветку |
| git branch -d <имя_ветки> | Безопасное удаление ветки (если её изменения слиты) |

---

### Работа с удалённым репозиторием

| Команда | Описание и назначение |
| --- | --- |
| git remote add origin <URL> | Привязка удалённого репозитория под именем origin. |
| git remote -v | Проверка привязанных URL-адресов удалённого репозитория |
| git push -u origin <ветка> | Первичная отправка ветки на сервер с установкой отслеживания (upstream) |
| git push --set-upstream origin <ветка> | Настройка связывания локальной ветки с удалённой при отправке |
| git push | Отправка локальных коммитов в удалённый репозиторий |
| git pull | Получение и слияние последних изменений с сервера. |
| git fetch --prune | Обновление информации об удалённых ветках и удаление устаревших локальных ссылок. |

#### Исключение файлов (.gitignore)

Файл .gitignore размещается в корне проекта и указывает Git, какие каталоги и файлы не должны попадать в систему контроля версий:

### Возможные проблемы

- Зависание терминала при got log
Решение: q - выход из режима
- .gitignore не был вовремя создан и в коммит улетели ненужные файлы
Решение: создание + заполнение .gitignore + git rm -r --cached и заново добавить файлы в индекс (--cached удаляет файлы ток из отслеживания но не с диска пк)
